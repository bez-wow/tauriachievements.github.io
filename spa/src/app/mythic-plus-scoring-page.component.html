How the scores are calculated

Every run gets a run score from its key level and clear time. A character's player score is then built from their best runs.

Runs Run score

The key level decides almost everything. The clear time only sorts runs of the same level.

Timed run

50 + 7.5 × level + 12.5 × (1 − time ÷ timer)

  • 50 points for finishing a key at all.
  • 7.5 points per key level, so a +20 is worth 150.
  • Up to 12.5 bonus points for finishing under the timer. The faster you are, the bigger the bonus. Finishing right on the timer gives 0.

The bonus follows the exact clear time, not the keystone upgrade. A +2 chest at 61% and one at 79% get different bonuses.

Over time (depleted)

50 + 7.5 × (level − 1) − 20 × (time ÷ timer − 1)

  • The run is scored one key level lower.
  • It then loses 20 points per full timer length it ran over: 5% over costs 1 point, 50% over costs 10.
  • A score never goes below 0.

Good to know

  • Scores are rounded to one decimal.
  • Affixes add nothing on their own; they come with the key level.
  • Equal scores are ordered by the faster clear time.
  • The rank colour compares a run with the season's best run: best, 90%+, 84%+, 76%+, below 76%.

Players Player score

A player's score is the sum of their best run score in each dungeon.

best EOA + best DHT + best BRH + … + best COS

  • Only one run per dungeon counts, the highest-scoring one. If two runs score the same, the faster one counts.
  • A dungeon with no run adds 0, so playing every dungeon counts for much more than repeating one.
  • Depleted runs count too, with their lower score, until a better run in that dungeon replaces them.

Filters change what counts

  • Dungeon picked: the score is simply the player's best run in that dungeon.
  • Class or spec filter: only runs played as that class or spec count. A player with a Blood and a Frost run is scored on the Blood run alone under a Blood filter. Ranks are renumbered for the filtered list.
  • Player search: only hides rows. Everyone keeps their real rank.

Good to know

  • A player is one character on one realm, whatever specs they played.
  • The spec shown is the one from the player's highest-scoring run.
  • Equal player scores are ordered by name.
  • The rank colour compares a player with the top player in the current list, using the same steps as runs: top, 90%+, 84%+, 76%+, below 76%.
  • Scores refresh once a day with the leaderboard data.
